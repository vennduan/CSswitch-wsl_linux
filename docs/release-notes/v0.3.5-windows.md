# CSSwitch v0.3.5-windows — Windows 冷启动修复

这一版专门解决 Windows 上「一键开始失败 / 沙箱起后探活超时」。上一版（v0.3.4）在真实客户
机器上暴露出一个我们没测到的问题：程序等 Claude Science 起来的时间不够长，而且**超时后会
把还在解压的进程杀掉**，导致越试越糟。本版把这条链路修掉，并加了自动重试。

**Windows 用户请整包重装本版，不要用旧版本覆盖。**

## 下载哪个文件

- **Windows x64（绝大多数 Intel / AMD 机器）**：`CSSwitch_0.3.5_x64-setup.exe`
- **Windows arm64（Windows on Arm）**：`CSSwitch_0.3.5_arm64-setup.exe`
- **macOS Apple Silicon（M 系列）**：`CSSwitch_0.3.5_aarch64.dmg`
- `csswitch-helper-linux-*` 是「远程服务器 / WSL 模式」用的辅助二进制，不是桌面安装包，普通用户不用下载。

## 开始之前：两件必须自己做的事

CSSwitch **不分发** Anthropic 的软件，也**不内置**第三方模型服务。它只负责把 Claude Science 的模型
推理转到你自己的 API 上，所以这两样要你自己准备：

1. **安装官方 Claude Science**（Windows 版）。CSSwitch 会驱动它自带的命令行组件，请保持默认安装
   位置（`%LOCALAPPDATA%\Programs\ClaudeScience`）。建议使用 **0.1.50** 版本——本版的自动进入机制
   是针对该版本验证的。
2. **安装 Python 3 正式版**（<https://www.python.org/downloads/windows/>）。
   ⚠️ **不要用 Microsoft Store 里的 Python**：那个版本在命令行里会静默退出，容易被误判成「没装」。
   装完记得勾选「Add Python to PATH」。

本地模式**不需要** bash、不需要 WSL、不需要装 Node。

装好后：打开 CSSwitch → 选 provider → 填你的 API Key → 点「一键开始」→ 浏览器会自动打开并
**直接进入 Claude Science 工作区**（中间的中转页已由程序自动完成，无需手动点击）。

## 本次修复

- **「沙箱起后探活超时」**：程序原来只等 20 秒。Claude Science 首次启动时要先把自己的运行时
  文件（约 124 MB）解压到工作目录，之后才开始监听端口——我们实测这一步就要 16 秒，
  磁盘慢或杀毒软件在扫描的机器必然超时。现在等待时间放宽到 180 秒。
- **越试越坏的连锁反应**：以前一旦超时，程序会把**还在解压的进程**直接杀掉，留下一堆半成品
  文件，导致下一次启动在同一个位置再次失败。现在不会乱杀；失败时自动清理残留并重试一次。
- **启动失败时自动修复**：如果确认是「运行时文件解压被系统拒绝」（杀毒软件占用或权限不足），
  程序会自动清理半成品目录，并复用官方安装目录里已经解压好的那份文件，然后重试。
- **报错更诚实**：以前只说一句「探活超时」，看不到真实原因。现在会把 Claude Science 自己的
  原始报错显示出来，并明确告诉你该怎么做（关掉杀毒软件的实时防护，或用管理员身份运行一次让
  文件落地）。
- **可自定义 Python 路径**：如果程序仍然提示找不到 Python，可以在「列表页 → 高级设置」里填
  `python.exe` 的完整路径（例如 `C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\python.exe`）。
  填了就优先用它。

## 如果还是失败

按顺序试：

1. **先关掉杀毒软件的实时防护**再点「一键开始」——文件解压被拦是最常见的原因。
2. **用「以管理员身份运行」启动一次 CSSwitch**，等它把文件解压完（这一步可能要一两分钟），
   然后关掉，再用普通方式启动即可。之后不再需要管理员权限。
3. 仍然失败的话，把 `C:\Users\你的用户名\.csswitch\logs\sandbox.log` 发给我们，里面有
   程序的完整日志。

## 已知限制

- Windows 安装包**未做代码签名**，首次安装可能弹 SmartScreen 提示——请只从本仓库 Release 下载，
  或让管理员临时放行。
- macOS 包是 ad-hoc 签名、**未做公证**，首次打开请用「右键 → 打开」，或在「系统设置 → 隐私与安全性」
  里点「仍要打开」。目前只提供 Apple Silicon（M 系列）版本。
- 官方 **Claude Science 桌面客户端**（独立窗口的那个 Electron 应用）仍然要求用它自己的官方账号
  登录，这与 CSSwitch 无关：CSSwitch 接管的是 Claude Science 的**网页端**（浏览器里那套），
  官方桌面客户端连的是它自己的服务，本项目不做干预。
- 第三方 API 的可用性、额度与内容政策由该服务商负责。
