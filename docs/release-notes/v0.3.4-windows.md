# CSSwitch v0.3.4-windows — Windows 本地模式可用性修复

这一版把 CSSwitch 的 **Windows 本地模式**真正修到可用：此前它在 Windows 上虽然能启动，但沙箱一直
没能用上 CSSwitch 准备的隔离登录态，界面上会看到登录页；同时还有闪窗、整机卡顿、窗口卡死关不掉、
误报缺少 Python、停止谎报成功等一串问题。本版在真实 Windows 机器上跑通并逐条修复。

**Windows 用户请整包重装本版**，不要用旧版本覆盖。

## 下载哪个文件

- **Windows x64（绝大多数 Intel / AMD 机器）**：`CSSwitch_0.3.4_x64-setup.exe`
- **Windows arm64（Windows on Arm）**：`CSSwitch_0.3.4_arm64-setup.exe`
- **macOS Apple Silicon（M 系列）**：`CSSwitch_0.3.4_aarch64.dmg`
- `csswitch-helper-linux-*` 是「远程服务器 / WSL 模式」用的辅助二进制，不是桌面安装包，普通用户不用下载。

## 开始之前：两件必须自己做的事

CSSwitch **不分发** Anthropic 的软件，也**不内置**第三方模型服务。它只负责把 Claude Science 的模型
推理转到你自己的 API 上，所以这两样要你自己准备：

1. **安装官方 Claude Science**（Windows 版）。CSSwitch 会驱动它自带的命令行组件，请保持默认安装
   位置（`%LOCALAPPDATA%\Programs\ClaudeScience`）。建议使用 **0.1.50** 版本——本版的自动进入机制
   是针对该版本验证的。
2. **安装 Python 3 正式版**（<https://www.python.org/downloads/windows/>）。
   ⚠️ **不要用 Microsoft Store 里的 Python**：那个版本在命令行里会静默退出，容易被误判成「没装」。
   装完记得勾选「Add Python to PATH」。

本地模式**不需要** bash、不需要 WSL、不需要装 Node。

装好后：打开 CSSwitch → 选 provider → 填你的 API Key → 点「一键开始」→ 浏览器会自动打开并
**直接进入 Claude Science 工作区**（中间的中转页已由程序自动完成，无需手动点击）。

## 本次修复

- **沙箱没有用上隔离登录态（最关键的一条）**：程序原本只把 Science 的数据目录指到沙箱，而**登录态
  所在的目录不在其中**，于是 Science 回头去读你真实账号的目录。后果有两层：界面上看到登录页；
  更要紧的是，若你机器上存在真实登录凭证，Science 会**直接用你的真实账号运行**——而 CSSwitch 的
  隔离承诺是「推理走你自己的 API、身份也是隔离的」。本版把登录态也钉回沙箱目录，现在只会用
  CSSwitch 准备的隔离身份（`virtual@localhost.invalid`），你的真实凭证目录保持只读。
- **每 2.5 秒闪一个 DOS 窗口**：已消除。
- **整机卡顿但 CPU / 内存不高**：已消除（成因是高频拉起子进程被安全软件拖慢）。
- **窗口「未响应」、关不掉**：已修复（阻塞操作已移出界面线程，并加了超时上限）。
- **明明装了 Python 却提示「缺少解释器」**：已修复（Microsoft Store 的占位程序不再挡住真解释器）。
- **点「停止」谎报成功**：已修复（现在以端口是否真的释放为准）。
- **把自己刚启动的沙箱误判成「端口被别的服务占用」**：已修复。

## 本次新增

- **一键进入，不再需要手动点一次**：Claude Science 的登录是一个一次性令牌的中转页（厂商为避免
  用 GET 建立会话而做的设计，不是故障）。本版由程序自动完成这一步：它会在本机回环地址上起一个
  临时的小页面（只监听随机端口、只含一次性令牌、**不含任何密钥**），让浏览器自动提交，登录全程
  你无需操作。任何一步不成立时都会自动回落成「手动点一次」，不会因此打不开。
- **内置 Linux 辅助程序**：远程服务器 / WSL 模式不再需要从网上下载辅助程序。

## 已知限制

- Windows 安装包**未做代码签名**，首次安装可能弹 SmartScreen 提示——请只从本仓库 Release 下载，
  或让管理员临时放行。
- macOS 包是 ad-hoc 签名、**未做公证**，首次打开请用「右键 → 打开」，或在「系统设置 → 隐私与安全性」
  里点「仍要打开」。目前只提供 Apple Silicon（M 系列）版本。
- 官方 **Claude Science 桌面客户端**（独立窗口的那个 Electron 应用）仍然要求用它自己的官方账号
  登录，这与 CSSwitch 无关：CSSwitch 接管的是 Claude Science 的**网页端**（浏览器里那套），
  官方桌面客户端连的是它自己的服务，本项目不做干预。
- 第三方 API 的可用性、额度与内容政策由该服务商负责。
