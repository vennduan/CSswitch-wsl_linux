# CSSwitch v0.3.6-windows — 端口占用真因自愈

这一版解决 v0.3.5 仍然存在的「**一直停在启动中，约 3 分钟后才报错**」。

v0.3.5 已经把等待时间放宽到 180 秒、也加了重试，但**把故障原因判错了**：
它一直说「是上一次运行残留的 Claude Science 进程，请点『全部停止』」——
在**大多数**客户机上确实如此，但**在装了杀毒软件（尤其金山毒霸）的机器上完全不是**：
占着端口的是一个**系统服务进程**，普通权限根本杀不掉，所以「点全部停止」没有任何用。

本版把这件事做对：认得出占用者是谁、说对话、并且**自动绕开**。

**Windows 用户请整包重装本版，不要用旧版本覆盖。**

## 下载哪个文件

- **Windows x64（绝大多数 Intel / AMD 机器）**：`CSSwitch_0.3.6_x64-setup.exe`
- **Windows arm64（Windows on Arm）**：`CSSwitch_0.3.6_arm64-setup.exe`
- `csswitch-helper-linux-*` 是「远程服务器 / WSL 模式」用的辅助二进制，不是桌面安装包，普通用户不用下载。

## 还没装本版？先用这招手动解决（立刻生效）

先别等程序更新——**改一个端口就能起来**：

1. 打开 CSSwitch → **列表页 → 高级设置** → 把**沙箱端口**从 `8990` 改成 `8991`
   （**只改沙箱端口**，代理端口 `18991` 不要动）。
2. 点「一键开始」。

如果 `8991` 也被占，就改成 `8992`、`8993`……往下顺延即可。

怎么确认哪个端口空着（管理员 PowerShell 或普通 PowerShell 都行）：

```powershell
Get-NetTCPConnection -State Listen |
  Where-Object { $_.LocalPort -ge 8990 -and $_.LocalPort -le 9020 } |
  Select-Object LocalPort, OwningProcess
```

没有输出 = 这一段端口都空着，随便挑一个。

首次启动要展开 Claude Science 的运行时文件（约 124 MB），**请等 1～2 分钟**再判断成败。

## 本版修了什么

- **报错终于点名占用者**：程序现在会查出占端口的进程**叫什么名字**，并按类型给建议：
  - **杀毒软件 / 系统服务的常驻进程**（比如金山毒霸 `kxescore.exe`）：
    明确告诉你「普通权限结束不掉，请退出该软件，或在高级设置里换一个沙箱端口」；
  - **本程序上次残留的 Claude Science 进程**：告诉你点「全部停止」再重试；
  - **其它第三方程序**：如实说明，不会乱建议。
- **端口被外部程序占用 → 自动顺延**：起沙箱前发现端口被占（且不是自家进程），
  程序会**自动往后找一个空闲端口**继续启动，并告诉你「已改用端口 XXXX」。
  多数情况下你什么都不用改，直接点「一键开始」就行。
- **失败要快，不再白等 3 分钟**：以前要干等满 180 秒才报错。现在一旦确认这次启动已经
  失败（例如启动器报 `exited before becoming ready`），**几秒内**就给出真实原因。
- **能看到真实报错了**：端口冲突的原始报错其实写在 Claude Science 自己的
  `server-*.log` 里，程序以前**读的是另一个日志**，所以只能报「探活超时」这种没信息量的错。
  现在两处都读，原文带出来。
- **中文用户名 / 中文路径不再乱码**：程序在 Windows 上读进程信息时强制用 UTF-8 输出，
  中文用户名（如「梓昀」）下的路径不会解析失败。
- **绝不会误杀别人的程序**：只有确认占端口的是**本程序自己的**沙箱进程时才会去结束它。
  杀毒软件、别的程序一概不碰。

## 如果还是失败

按顺序试：

1. **先关掉杀毒软件的实时防护**再点「一键开始」——文件解压被拦是最常见的原因。
2. **用「以管理员身份运行」启动一次 CSSwitch**，等它把文件解压完（这一步可能要一两分钟），
   然后关掉，再用普通方式启动即可。之后不再需要管理员权限。
3. 如果报错说端口被某个**系统服务**占着（毒霸/360/火绒等），**改沙箱端口**最省事——
   见上面「手动解决」。
4. 仍然失败的话，把这两个文件发给我们，里面有完整日志：
   - `C:\Users\你的用户名\.csswitch\logs\sandbox.log`
   - `C:\Users\你的用户名\.csswitch\sandbox\home\.claude-science\logs\server-*.log`
     （**端口被占的原文在这里**，前一个文件里没有）

## 已知限制

- Windows 安装包**未做代码签名**，首次安装可能弹 SmartScreen 提示——请只从本仓库 Release 下载，
  或让管理员临时放行。
- 官方 **Claude Science 桌面客户端**（独立窗口的那个应用）仍然要求用它自己的官方账号
  登录，这与 CSSwitch 无关：CSSwitch 接管的是 Claude Science 的**网页端**（浏览器里那套），
  官方桌面客户端连的是它自己的服务，本项目不做干预。
- 第三方 API 的可用性、额度与内容政策由该服务商负责。
